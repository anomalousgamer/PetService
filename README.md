# Pet Service

Author: **Anomaly** · Version **0.4.0.1**

A private Pet/Master connection for FINAL FANTASY XIV. Open **/toh** or **/petservice** for the Pet and password-protected Master pages. The companion website is a separate package. The service connection is included in the plugin; pairing needs only the Master's one-time code.

The Pet pages offer Home, Contact, Tasks, Characters and Setup. The pet chooses which characters may use the connection and can pause it with the confirmed local kill switch. An unapproved character pauses all sharing and Master effects. Returning to an enabled character resumes the connection. Safe release frees gameplay for the current login.

The Master pages manage the same profiles, reminders, prompts, inventory, tasks, settings and history as the website. The global Master identity setting chooses a display name or the Master label and an optional supplied portrait. Both can be changed at any time.

Game chat and conversation partners remain private. Only intentional plugin replies and Contact requests are forwarded. Native game chat remains accessible while the supported gameplay guard is active. The game itself continues running.

| Command | Action |
|---|---|
| `/toh` or `/petservice` | Open the plugin. |
| `call` | Open Contact and choose a request. |
| `off` | Confirm the kill switch. |
| `on` | Resume the connection. |
| `release` | Release gameplay guarding for this login. |
| `changes` | Open What's New. |
| `checkupdates` | Check for a repository update. |

The supplied icon is included in downloads. No AI-generated artwork is included.

The gameplay controls show a remaining-time countdown and retained request/outcome history. Daily reminder previews show each custom reply’s behavior before saving. Moodles previews include game icons and descriptions, with a clear-all action for PetService-managed statuses. Control outcomes are reported to the configured Discord channel.
